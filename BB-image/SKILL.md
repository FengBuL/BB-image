# BB-image

## 默认用法（主流程）

用户会**先发一段正文**（未必点名风格 ID 或颜色）。你的任务是：

1. **读正文** → 提炼封面文案（主标题 ≤2 行、副句 1 行、可选眉题）；**把报道对象的品牌 / 产品名单独拎出来**，它是封面最大的识别信息  
2. **判色族** → 查 [COLOR-GUIDE.md](COLOR-GUIDE.md)，在 A 墨黑深底 / B 纸白浅底 / C 信号蓝满底 / D 红黑叙事 / E 上浅下深 里选 1 个  
3. **判风格** → 在该色族里，用 [THEME-GUIDE.md](THEME-GUIDE.md) 选出最贴的 **1 个首选**；若两种气质都成立，选 **2–3 个**（不要超过 3），且**尽量跨 2 个色族**  
4. **简短说明** → 用一两句话告诉用户：选了哪几个、各是什么色族、为什么  
5. **变奏 + 出图** → 读 [TYPOGRAPHY.md](TYPOGRAPHY.md)、[BRAND.md](BRAND.md)、[VARIATIONS.md](VARIATIONS.md)、对应 `styles/XX-*.md`，把 COLOR-GUIDE 里该色族的「色彩句」写进提示词，每套风格各生成 **1 张** 竖版封面；**`aspect_ratio` 一律 `3:4`**  
   - **若含风格 06**：出图前必须按 `styles/06-banner-matrix.md` 写死 L1=产品专名、L2=纯中文事件；提示词须带「禁止 SESSION BUDGET 类概念英巨字 / 禁止中英翻译叠罗汉」；自检不通过不得生图  
   - **若含风格 14**：有参考图则先读图；可**抽数据**和/或把参考图**同风格嵌进层叠样张**（生图带 reference）；无附图/正文无数则不画假 KPI  
6. **校验画幅** → 出图后读真实像素宽高，比例必须是 3:4（见「画幅」）；不对就重跑，**不要事后裁切、压缩或拉伸**  
7. **交给用户选** → 标明风格编号和色族；用户选定后可再按该风格精修/重跑

用户若已点名风格 ID 或色族，则跳过「多候选」，只出指定的。

### 批量：同一份文档多条内容

用户让你「给文档里的 N 条配图」时：

1. 每条 1 张，先列**配色表**（第几条 → 色族 → 风格），规则见 [COLOR-GUIDE.md](COLOR-GUIDE.md) 的「批量与多候选的配色」：整批深浅各一、相邻两张不同色族  
2. 配色表确认后再逐张出图，每张都走上面的 5–6 步  
3. 每张封面的品牌字标都要够大

### 选型输出格式（出图前）

```markdown
**封面文案**
- 主标题：…
- 副句：…
- 眉题（可选）：…
- 品牌字标：…（占宽 ≥ 1/3）

**色族**：A / B / C / D / E（一句话理由）

**候选风格**（2–3 个，或唯一 1 个）
1. **0X 名称**（色族 ?）— 理由（一句话）
2. **0Y 名称**（色族 ?）— 理由
3. **0Z 名称**（色族 ?）— 理由（若有）

开始按上述风格各生成 1 张供你选。
```

### 何时出 1 张 vs 2–3 张

| 情况 | 出图数 |
|------|--------|
| 正文类型非常明确（如明确线下场次 → 10） | **1** 张即可，可提一句备选但不强行多画 |
| 两种解读都成立（如「大模型发布」→ 14 或 06；「提速」有无数字 → 12 或 04） | **2–3** 张，让用户选 |
| 用户说「多给几个看看」 | 最多 **3** 张 |

## 核心原则

1. **正文驱动**：色族和风格由内容决定，不先问用户选编号（除非用户主动指定）。  
2. **先色后钩**：先判色族，再选钩子；多候选跨色族，批量相邻不同色族。  
3. **认人**：墨黑 / 信号蓝 / 纸白（见 BRAND）；**禁止用户名**。  
4. **字体细长偏淡**：所有文字用细体（Light/Thin）、颜色比纯黑纯白更淡；每条提示词必须附 [TYPOGRAPHY.md](TYPOGRAPHY.md) 的固定句。
5. **品牌字标要大**：报道对象的品牌 / 产品名占宽 ≥ 1/3，手机缩略图能读（见 COLOR-GUIDE）。  
6. **防重复**：每张至少改 3 个变奏轴，主视觉绑定本篇（见 VARIATIONS）。  
7. **禁止用户名**：封面不出现 SHOVY / @handle / 个人账号。  
   - **风格 12**：报道对象官方 logo 可作为柱顶标识。

## 画幅（强制）

| 项目 | 规范 |
|------|------|
| 比例 | **必须 3:4 竖版**，禁止 1:1、16:9、4:5 或其他比例 |
| 生图参数 | 调用图像工具时 `aspect_ratio` **固定传 `3:4`** |
| 分辨率建议 | 1080×1440 或同比例更高 |
| 文案量 | 封面不是长文；从正文压缩，勿整段贴上 |
| 校验 | 出图后读文件真实宽高，`宽/高 ≈ 0.75` 才算通过 |

凡提示词开头须含「竖版 3:4」。

**比例不对时**：重跑，或如实告诉用户当前生图工具没有按 3:4 出图，请用户换工具 / 选工具；**不要用裁切、压缩、拉伸、补边凑出 3:4**。用户明确改口指定了别的比例（如 2:3）时，以用户为准并原生生成。

## 红线

- 不把 15 套全跑一遍；最多 3 候选  
- 不省略信号蓝；禁止用户名水印  
- 同一张图不引入第二强调色（风格 10 的红仅作叙事渐变）  
- 品牌字标不得缩成角落小标签；但字体必须细长细体，禁止粗黑体 / Bold / 木刻粗字  
- **所有成图必须原生 3:4**（工具参数与提示词双约束，出图后校验像素）  
- 不临摹他牌封面  
- 多候选时每套风格钩子必须明显不同，方便用户并排挑选

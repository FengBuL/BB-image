# 03 · Letterform Object｜白底字中嵌物

**气质目标**：纯白大留白、超大字标与中央扁平物件咬合、下方悬浮胶囊工具条、底栏品牌脚注——产品发布的呼吸感。  
**禁止复刻**：特定品牌字标劈开方式作为唯一模板、官方吉祥物、可识别产品聊天条文案。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格浅族，底用 `PAPER`）
- 必须有一处 `SIGNAL` 点缀（嵌物浅蓝、工具条按钮或角标方点）
- 禁止引入第二品牌强调色（红/橙/绿/金）
- 母题 M3 角标方点可选

## 原创系统（贴气质，换细节）

- **底**：纸白 `PAPER` `#F3F1EC`
- **顶栏**：左可用像素/点阵小标签（系列名自定义）；右 `MIST` 色日期/主题元数据——保留「文档头」感
- **中央**：超大细长无衬线字标（中文或拉丁），**中部嵌入**一件扁平插画静物（电脑、镜头、植物、零件…随主题变）；插画以灰阶+**一抹信号蓝** `SIGNAL` 为主
- **工具条**：全圆角 `LINE` 描边悬浮胶囊，轻阴影；内含通用「+」、灰色占位句、右侧小 `SIGNAL` 按钮——表达「可对话的产品」，但控件文案/图标组合须原创，勿抄现有 AI 助手条
- **底栏**：`` + 细体名 + `MIST` 色制作说明
- **差异点**：字标可用两段式留白嵌物，不必左右对称四字母；静物题材随内容换新

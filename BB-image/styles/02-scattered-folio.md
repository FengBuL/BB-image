# 02 · Scattered Folio｜浅底作品卡墙

**气质目标**：浅灰白空气感、圆角白卡片透视散落、中心彩色作品、中性 UI 壳衬托——轻盈合集感。  
**禁止复刻**：特定品牌 App 图标、官方页脚文案、可识别的产品输入组件文案（如 Agent 胶囊）。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格浅族，底用 `PAPER`）
- 必须有一处 `SIGNAL` 点缀（标题下手绘笔触下划线或小方点）
- 禁止引入第二品牌强调色（红/橙/绿/金）；卡心作品彩色仅限内容插画，不作品牌强调
- 母题 M3 角标方点可选

## 原创系统（贴气质，换细节）

- **底**：纸白 `PAPER` `#F3F1EC`，可隐约极淡大字底纹（自定义系列名，低对比倾斜）
- **顶栏**：左`` 或纯文字系列名；居中/偏左大细长标题两行；关键词下用**信号蓝笔触下划线**（手绘感）
- **卡片**：4–6 张大圆角白卡，轻阴影，**透视微倾重叠**成墙
- **单卡结构**（保留「作品被 UI 托住」的感觉，但壳要原创）：
  1. 顶：左小标签（可像素体系列名）+ 右 `MIST` 色日期元数据  
  2. 中：主题化的彩色字标/插画（每卡风格不同）  
  3. 下：浅灰细边**工具条**——用通用控件隐喻（圆点菜单、短进度条、或「添加」图标+占位灰字），**不要**复制某产品的 Agent/模型切换条  
  4. 底：小号字标 + `MIST` 色制作说明
- **色**：页级中性；彩色只在卡心作品里；品牌强调仅用 `SIGNAL`

## 色板

| 角色 | 令牌 | 色值 |
|------|------|------|
| 页底 | `PAPER` | `#F3F1EC` |

**原理来源**：主体左右双材质劈开 + 细线标注 + 代码修辞点缀。  
**禁止复刻**：登月舱对半写实/抖动 + 金圆背光 + 原作联名锁版 + `{ Prompt 秘籍;` 底条。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格深族，底用 `INK`）
- 必须有一处 `SIGNAL` 点缀（标注线、光斑边缘或编号圆点）——**原苔绿标注改为 `SIGNAL`**
- 禁止引入第二品牌强调色（金/苔绿/珊瑚水彩作品牌色）；水彩叙事可保留中性暖调，但标注/CTA 用 `SIGNAL`
- 背光改为 `GLOW`/`PAPER` 冷光，非金色

## 原创系统

- 主体改为与主题相关的**文物/仪器**（收音机、罗盘、相机、服务器刀片等），由用户槽位决定  
- 劈开：左**水彩晕染**（中性暖调叙事），右**精密线稿爆炸图**——不是写实 3D vs 半色调登月舱  
- 背光形改为**横向长椭圆光斑**（灯管感，`GLOW` `#7EB6FF` 或 `PAPER` 冷白），非金色满月圆  
- 标注用**虚线引线 + 圆端编号**，字色 `SIGNAL`；底 CTA 用书名号式中文，可少量 `//` 但不用花括号秘籍句式  
- 底纹：极淡**等高线**（`MIST`），非二进制雨

# 13 · Tile Aperture｜瓷砖光圈

**原理来源**：网格底 + 倾斜画框制造破冰感与层次。  
**禁止复刻**：亮蓝方格 + 黑取景框里的蓝半圆竖眼吉祥物 + 黄钩白 HELLO 吊牌 + 红「小红书科技」胶囊锁版。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格浅族，底用 `PAPER`）
- 必须有一处 `SIGNAL` 点缀（瓷砖缝、画框内光圈或行李牌挂绳）
- 禁止引入第二品牌强调色（陶土/亮蓝方格/黄钩/红胶囊）；**原陶土砖改为 `PAPER`/`LINE` 网格**
- 保持画廊画框+光圈钩子

## 原创系统

- 底：**纸白 `PAPER` 六角砖**铺贴（`LINE` 缝），非亮蓝四方格或陶土色  
- 画框：纸白/木感 `PAPER` **斜框**，像画廊画框，不是细体 UI 取景框；框边可加 `SIGNAL` 细线  
- 框内：抽象**光圈/镜头叶片**图形（几何，`INK` 石墨色），或用户品牌单色符号——**禁止竖眼圆球**；叶片中一颗 `SIGNAL` 节点  
- 吊牌改为**金属行李牌**挂在框角，刻字感 HELLO；徽章用用户活动名 + ``，不用平台红胶囊仿制品

# 07 · Spec Window｜暗色规格框

**气质目标**：纯黑底、亮蓝细线圆角大框、等宽元数据、左大号产品名+版本、右侧抽象点阵图形——开发者工具发布感。  
**禁止复刻**：特定产品 URL/功能树原文、官方图标字形。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格深族，底用 `INK`）
- 必须有一处 `SIGNAL` 点缀（框描边、顶栏标识或点阵渐变中的信号蓝节点）
- 禁止引入第二品牌强调色（红/橙/绿/金）
- 所有蓝均为 `SIGNAL`，不得换用其他科技蓝

## 原创系统（贴气质，换细节）

- **底**：墨黑 `INK` `#0B0D10`
- **顶区**：左小 `SIGNAL` 标识（几何原创，勿仿他牌）；右等宽站点/路径；其下 1–2 行功能短句，细横线分隔——保留「系统状态头」
- **主框**：`SIGNAL` 细描边**大圆角矩形**；框内左：大白无衬线产品名 + 版本号；左下等宽日期``
- **右侧锚点**：大半幅抽象图形——点阵/微字符渐变场（上浅下 `SIGNAL` 或径向），形状可以是半圆、扇形、角矩形，**每次换轮廓**，避免固定同一半圆字场
- **差异点**：顶栏信息架构可保留，文案与小图标原创

## 色板

| 角色 | 令牌 | 色值 |
|------|------|------|
| 底 | `INK` | `#0B0D10` |
| 框/标识 | `SIGNAL` | `#2F5BFF` |
| 字 | 白 | `#FFFFFF` |
| 点阵渐变 | 白 → `SIGNAL` / `GLOW` | `#FFFFFF` → `#2F5BFF` / `#7EB6FF` |
| 元数据 | `MIST` | `#9AA3B2` |

# 08 · Grid Changelog｜瑞士更新网格

**气质目标**：浅灰白底、细顶底线、宽字距元数据、Release 蓝小字、大黑标题、**2×2 功能格且仅一格实心蓝底白字**——冷静工程日志。  
**禁止复刻**：特定产品桌面端更新原文与功能名锁版。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格浅族，底用 `PAPER`）
- 必须有一处 `SIGNAL` 点缀（版本行、实心格或底栏信号蓝短划）
- 禁止引入第二品牌强调色（红/橙/绿/金）；**实心格必须为 `SIGNAL` 蓝，不得用绿/钴蓝**
- 四宫格+单格涂蓝为气质核心，格色统一信号蓝

## 原创系统（贴气质，换细节）

- **底**：纸白 `PAPER` `#F3F1EC`
- **结构**：顶细线 + 左产品线小大写 + 右日期 → `SIGNAL` 小字版本行 → 大黑标题 → 两行说明 → **2×2 格** → 底细线 + 左日志标签 + 右页码
- **焦点**：四格中**仅一格**实心信号蓝 `SIGNAL` `#2F5BFF` 白字，其余 `LINE` 浅灰底黑字；每格左上编号 `01`–`04`，中央大号功能名
- **字体**：现代无衬线；元数据宽字距小大写
- **差异点**：强调格位置可轮换（默认左上）；功能文案用户自填；栏间距与圆角可微调，但**保持四宫格+单格涂信号蓝**这一气质核心

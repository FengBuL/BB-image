# 14 · Stack of Surfaces｜层叠界面

**原理来源**：暗底上多层界面浮层表达「能力集合 / 大发布」。  
**禁止复刻**：衬线原作模型名+ 特定四窗内容（山体/邮件/Remington/数据看板）+ 压字「模型发布」锁版。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格深族，底用 `INK`）
- 必须有一处 `SIGNAL` 点缀（样张标注点、压字下划线或角标方点）
- 禁止引入第二品牌强调色（靛蓝/荧光粉/紫）
- 深底用 `INK`，样张用 `PAPER`

## 用户提供参考图时（两种用法，可并用）

### A. 抽数据

1. 读图，提取可读数字、系列名、单位、对比关系，列表公示  
2. 看不清的不猜；只用不存疑的值  
3. 可用提取结果**重绘**进样张（配色跟 BRAND）

### B. 原图入画（同风格嵌进层叠）

参考图**可以直接成为浮层里的一张（或两张）样张**，不是只能抽象成数字：

1. 将参考图做成错位悬浮的**纸质/印刷样张**：圆角或纸边、轻阴影、微倾，贴合 14 的层叠气质  
2. **同风格处理**：整体套进墨黑底 + 纸白卡；可加极淡印刷网点、`SIGNAL` 小标注点；勿改成无关的玻璃拟态乱窗  
3. 生图时若工具支持，传入 `reference_image_paths`（用户附图路径），提示词写明「把参考图作为其中一张悬浮样张嵌入，保持可辨认」  
4. 其余 1–2 张样张：可继续用抽到的数据重绘，或正文相关的无数值示意，形成 2–3 层叠  
5. 仍遵守：参考图里没有的数，不要在旁卡上编造  

### 无参考图、正文也无数

样张只用无数值示意，不出现假 KPI。

### 数据出处（有数才画数）

仅限：正文写明的数 / 参考图提取的数 / 用户明确给出的表。禁止虚构。

### 自检

- [ ] 每个数字有出处？  
- [ ] 若用户要「参考图入画」：画面里是否能认出参考图内容（而非完全丢掉）？  
- [ ] 嵌入后是否仍是 14 的层叠印刷感（墨黑底 + 错位样张 + 压字）？  

## 原创系统

- 底：墨黑 `INK`，印刷网点  
- 浮层 **2–3 张**错位样张：含「参考图入画」卡和/或数据重绘卡和/或示意卡  
- 超大细长中文压字；顶可有产品名小字；`SIGNAL` 点缀  

## 色板

| 角色 | 令牌 | 色值 |
|------|------|------|
| 底 | `INK` | `#0B0D10` |
| 样张 | `PAPER` | `#F3F1EC` |
| 样张线 | `SIGNAL` / `MIST` | `#2F5BFF` / `#9AA3B2` |
| 压字 | 白 | `#FFFFFF` |
| 标注点 | `SIGNAL` | `#2F5BFF` |

## 提示词模板

```
竖版 3:4。画幅强制竖版 3:4，禁止其他比例。
竖版原创发布海报。墨黑 {{INK}} 底带印刷网点。两到三张错位纸白 {{PAPER}} 样张悬浮。
{{ref_instruction}}
样张补充：「{{panel_desc}}」。
【数据】仅用已核实值：{{verified_data}}（无则不画假数）。
其上压超大细长暖白中文「{{hook}}」。底「{{line1}}」「{{line2}}」。
信号蓝 {{SIGNAL}} 小点。禁止用户名。个人视觉 SIGNAL+INK+PAPER。
```

### 槽位

| 槽位 | 含义 |
|------|------|
| `ref_instruction` | 有参考图时写：`将用户参考图作为其中一张微倾悬浮印刷样张嵌入，保持图表/画面可辨认，统一纸边阴影与本海报风格`；无参考图则写 `无参考图嵌入` |
| `verified_data` | 提取列表，或 `无` |
| `panel_desc` | 其余样张内容 |
| `hook` / `line1` / `line2` | 来自正文 |

生图调用：若有用户附图，设置 `reference_image_paths` 指向该文件。

# 12 · Impact Metrics｜冲击指标

**原理来源**：动感线 + 柱状对比 + 标识与数据互动。  
**禁止复刻**：奶油底黑放射线 + 斜蓝横幅「再提速」+ 墨镜蓝球开红飞机掠过柱顶的锁版。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**（本风格深族，底用 `INK`）
- 必须有一处 `SIGNAL` 点缀（横幅、最高柱或粒子尾迹中的信号蓝节点）
- 禁止引入第二**个人品牌**强调色；横幅与新高值柱用 `SIGNAL`
- 保持动感柱图钩子，色系统一为墨黑+信号蓝

## 原创系统

- 底：**墨黑 `INK`** `#0B0D10`；动感线为**白色短破折号粒子尾迹**，可含 `SIGNAL` 微光点  
- 横幅：水平**信号蓝 `SIGNAL` 告示条**白字  
- 柱状图：**圆柱体等距**；旧值 `MIST` 灰、新值 `SIGNAL` 蓝  
- **柱顶标识（强制）**：使用正文所涉产品/公司的**官方 logo**（或用户提供的 logo 素材），置于对应柱顶或最高柱上  
  - 例：讲 Claude / Opus → Anthropic Claude logo；讲 GPT → OpenAI logo；讲 Cursor → Cursor logo；多模型对比 → **每根柱顶各用对应 logo**  
  - Logo 保持可识别、简洁，可小幅简化但不变形歪曲到无法辨认  
  - **禁止**狐狸、小鸟等动物吉祥物；禁止飞机、墨镜蓝球等无关角色  
  - 若正文无明确品牌、纯抽象指标 → 柱顶用几何小标或纯数字，仍不用动物  

## 色板

| 角色 | 令牌 | 色值 |
|------|------|------|
| 底 | `INK` | `#0B0D10` |
| 横幅/新柱 | `SIGNAL` | `#2F5BFF` |
| 旧柱 | `MIST` | `#9AA3B2` |
| 粒子/字 | 白 | `#FFFFFF` |
| 微光 | `GLOW` | `#7EB6FF` |

### 槽位说明

- `logo_spec`：根据正文填写，如 `Claude/Anthropic 官方星形 logo 在 Opus 相关柱顶`；多系列对比写清每柱对应谁。

# 06 · Banner Matrix｜旗标矩阵

**原理来源**：上区声明、下区纹理图形的二分信息结构。  
**禁止复刻**：纯黑头+七蓝点分隔+浅蓝 `[]` 底+深蓝 ASCII 箭头剪影+右下原作品牌角标的组合。

## 品牌服从

- 必须使用 `BRAND.md` 令牌：`INK` / `SIGNAL` / `PAPER`；**禁止出现用户名/SHOVY/@handle**
- 必须有一处 `SIGNAL` 点缀（交界细线或一颗信号蓝方块）
- 禁止第二品牌强调色；下区纹理用 `MIST`/`LINE` 方块

---

## 上区文案：只准两行（硬约束）

出图前先写死这两行，**禁止再增加第三行主标题**：

| 行 | 内容 | 字号 | 语言 |
|----|------|------|------|
| **L1** | 主语 = 产品/功能全名（专名） | **全图最大** | 专名原文（多为英文产品名） |
| **L2** | 谓语 + 宾语 = 发生了什么 | 次大 | **仅中文** |

可选：双细线里极短标签（≤3 个词，如 `NEW · CAP · RESUME`），**不算主标题**，不得写成 `SESSION BUDGET` 这种概念标题。

### 绝对禁止（叠罗汉黑名单）

生成图里**不得出现**下列任一情况：

1. **概念英文化主标题**：`SESSION BUDGET` / `AGENT PLUGINS` / `NEW PLANS` / `MCP RULES` / `MODEL RELEASE` 等——把「事件对象」做成英文巨字  
2. **中英翻译对叠**：同一意思上下两行，例如  
   - `SESSION BUDGET` + `会话可设预算`  
   - `SESSION BUDGET` + `会话预算`  
   - `Released` + `已发布`  
3. **主语缩成顶栏小字**：Claude Managed Agents 只出现在顶部 10px 灰字，主视觉却是 Budget  
4. **VARIATIONS 全局「上英下中」**：本风格**不适用**；见下方覆盖规则  

### 判定口诀

> 英文巨字只允许是「专有名词主语」，不允许是「中文意思的英文翻译」。

- ✅ `Claude Managed Agents`（专名）  
- ❌ `SESSION BUDGET`（「会话预算」的英文翻译/概念标）  
- ✅ L2：`上线会话预算`  
- ❌ L2 旁再写 `Session Budget Live`

### 正确填写示例

```
L1: Claude Managed Agents
L2: 上线会话预算
```

```
L1: Cursor Agent Plugins
L2: 官方确认支持
```

### 出图前自检（不通过不得调用生图）

- [ ] L1 是否等于正文里的**产品名**，且为全图最大字？  
- [ ] L2 是否为**纯中文**事件句？  
- [ ] 画面上是否还有第三行英文概念标题（Budget / Release / Update / Plugins 当巨字）？有则删掉重出  
- [ ] 是否存在中英两行意思相同？有则删英文概念行

## 提示词模板（必须整段使用）

出图时 **L1/L2 先填进提示词**，并复制禁止清单：

```
竖版 3:4 发布海报（强制 3:4，禁止其他比例），上区纸白 {{PAPER}}，下区墨黑 {{INK}}。

【上区只准两行主文案，禁止第三行巨字】
第1行（全图最大）：「{{subject}}」
第2行（次大，仅中文）：「{{action_zh}}」

硬性禁止出现这些字样作为大标题或主视觉英文行：
SESSION BUDGET、Session Budget、AGENT PLUGINS、NEW PLANS、MCP RULES、MODEL RELEASE，
以及任何「中文事件的英文翻译」巨字。
禁止中英对照叠罗汉（同一意思上下两行）。
禁止把产品名缩成顶部小灰字。

可选：双细线内极短标签「{{rule}}」（非主标题）。
下区：浅灰轴测方块纹理+负形缺口；交界一条信号蓝 {{SIGNAL}} 细线。
画幅强制竖版 3:4，禁止其他比例。
禁止用户名。个人视觉 SIGNAL+INK+PAPER。原创。
```
Agent 填写时：

- `subject` ← 正文产品全名（如 Claude Managed Agents）  
- `action_zh` ← 仅中文（如上线会话预算）  
- **不要**再设 `title` / `title_zh` 双语对

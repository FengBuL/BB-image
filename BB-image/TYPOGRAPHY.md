# 字体规范（全部风格强制：细长、偏淡）

用户偏好：**所有封面的文字都用细长字体、颜色稍淡**，不要粗大的黑体效果。本文件优先级高于各 `styles/XX-*.md` 里任何「粗 / 超大 / 木刻 / Heavy / Bold」类字重描述。

## 规则

1. **字重**：全部文字用 Light / Thin 细体（中文用细黑、纤细宋体或细长黑体风），窄长比例，字距略松。禁止粗黑体、Bold、Heavy、木刻粗字。
2. **品牌字标**（如 CLAUDE）：仍占画布宽度 ≥ 1/3，但用**细长细体大写**，靠尺寸而不是笔画粗细来醒目。
3. **颜色稍淡**：深底用淡灰白（约 `#D9DBDF`，蓝底用 `#EEF2FF`），不用纯白；浅底用淡墨灰（约 `#3A3D44`），不用纯黑。`SIGNAL` 蓝仍是唯一强调色。
4. **大标题**：靠字号和留白出气势，笔画保持纤细；衬线只在一行里用，且是细衬线。
5. **色块上的字**（如实心信号蓝格）：细体白字，不加粗。
6. **画面**：整体克制、留白多，不压粗字盖住画面主体。

## 提示词固定句（每张都必须附上）

```
字体：全部文字使用纤细、修长、高挑的细体字（Light / Thin 字重，窄长比例，字距略松），主字颜色比纯黑纯白更淡更柔和；禁止粗黑体、超粗字重、木刻粗字。品牌字标用细长细体大写，宽度占画布三分之一以上，不加粗。
```

## 自检

- [ ] 画面里没有粗黑体、Bold、木刻粗字？
- [ ] 品牌字标是细长细体且占宽 ≥ 1/3？
- [ ] 主字颜色比纯黑 / 纯白更淡？

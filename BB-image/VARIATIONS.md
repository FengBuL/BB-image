# 变奏引擎：同风格不重复

问题：同一风格 ID 若元素配方写死，换文案也会像同一张图 → 16 风格 ≈ 16 张图。  
解法：**三层分离**——品牌 DNA 固定、风格钩子类型固定、**镜头变奏每次重抽**。

```
BRAND（认人，不变）
  └── STYLE 钩子类型（01=暗轨 / 02=卡墙 / …，类型不变）
        └── SHOT 变奏（每次生成必须重配，且绑定本次内容）
```

---

## 强制规则（每次出图）

1. **内容绑定**：主视觉必须从**本篇标题/主题**长出来（物件、剪影、卡心画、柱状含义、溶字词），禁止复用上篇的具体图形配方。  
2. **至少改 3 轴**：在下方该风格的变奏轴里，相对「默认配方」或「上一张同风格」至少切换 **3** 个轴。  
3. **先写变奏卡再出图**：生成前提示词里先输出一张「本次变奏卡」（见文末模板），再写完整提示词。  
4. **禁止复制粘贴**：不得把风格稿里的示例弧数、卡数、静物、剪影形状当唯一答案。  
5. **品牌仍服从** [BRAND.md](BRAND.md)：换的是构图细节，不是三色；禁止用户名。

## 分风格变奏轴

| 轴 | 选项 |

## 本次变奏卡（出图前必填）

```markdown
### 本次变奏卡
- 风格 ID：
- 本篇主题一句话：
- 内容绑定主视觉：（写具体物/形，勿空）
- 全局轴：排版轴=；疏密=；信号蓝形态=；
- 本风格轴：（列出至少 3 个已选项）
- 与上一张同风格的差异：（若无上一张写「首张」）
```

将变奏卡选项 **写进提示词正文**，不要只写风格名。

# 色族选型（先定色，再定钩子）

**调用约定**：读完正文后，**先判色族 A–E，再在该色族里选风格钩子**。色族决定整张图的底色、字色和气质；钩子（01–16）决定构图。  
色值一律来自 [BRAND.md](BRAND.md)，这里只规定「什么时候用哪一族、各占多少」。

## 五个色族

| 色族 | 底 | 主字 | 强调 | 包含风格 | 气质 |
|------|----|------|------|----------|------|
| **A 墨黑深底** | `INK` | 白 / `PAPER` | `SIGNAL` | 01 05 07 09 12 14 16 | 高级、发布感、硬核、仪式 |
| **B 纸白浅底** | `PAPER` | `INK` | `SIGNAL` | 02 03 08 13 15 | 干净、产品、好呼吸、日常 |
| **C 信号蓝满底** | `SIGNAL` 全出血 | 白 / `PAPER` | `INK` 小块反衬 | 04 | 速度、冲击、技术宣言 |
| **D 红黑叙事** | `INK` → 红渐变 | 白 | `SIGNAL` 小点缀 | 10 | 活动、抢票、高能预告 |
| **E 上浅下深分区** | 上 `PAPER`，下 `INK`（或灰块纹理） | `INK` / 白 | `SIGNAL` 交界线 | 06 | 公告、开源、二分信息 |

## 色彩占比（默认值）

| 色族 | 底 | 主字 | `SIGNAL` | 其他 |
|------|----|------|----------|------|
| A | `INK` 70–80% | 白 / `PAPER` 15–20% | ≤ 8% | `MIST` 仅元数据 |
| B | `PAPER` 70–80% | `INK` 15–20% | ≤ 10%（一格实心块可到 20%） | `LINE` 分割、`MIST` 元数据 |
| C | `SIGNAL` 85%+ | 白 / `PAPER` | — | `INK` 小块 ≤ 10% |
| D | `INK` 上半 + 红渐变下半 | 白 | ≤ 3%（但必须出现） | 红只用于渐变与溶字，不作强调色 |
| E | 上 `PAPER` 35% / 下 `INK` 65% | `INK` / 白 | 交界细线或一颗方块 | 下区纹理用 `MIST` / `LINE` |

## 对比与可读性

1. 深底上主信息用白或 `PAPER`；`MIST` **只做元数据**（日期、页码、小标签），不承载主信息。  
2. 浅底上主信息用 `INK`；`SIGNAL` 做点缀或实心格，不做长段正文。  
3. 满蓝底（C）上文字只用白 / `PAPER`，不用 `SIGNAL` 色字。  
4. 红黑（D）里红色不替代 `SIGNAL` 认人，`SIGNAL` 必须出现。  
5. 同一张图最多一个强调色（`SIGNAL`），不得再出现第二强调色。

## 品牌字标可读性（所有色族）

报道对象的品牌 / 产品名（如 GLM-5.3、CLAUDE）是封面的**主识别信息**：

- 必须是画面里**最大的两组字之一**，或横向占画布宽度 **≥ 1/3**。  
- 在手机缩略图（约 1/4 尺寸）下仍能一眼读出。  
- 不得做成角落小标签或灰色元数据。  
- 用户自己的名字 / 账号 / `SHOVY` 仍然**禁止**出现。

## 批量与多候选的配色

- **多候选（同一条内容 2–3 套）**：尽量跨 **2 个色族**（如 A + B），方便并排挑选；不要三张同色族。  
- **批量（同一份文档的多条内容，各 1 张）**：整批至少含深、浅各一族；**相邻两张不同色族**；同一批里同一色族不超过 2 张。  
- 批量时先列一张「配色表」（第几条 → 色族 → 风格），再出图。

示例（3 条精选，按 A → B → A 排布）：

| 条目 | 色族 | 风格 |
|------|------|------|
| 大模型 API 上线 | A | 14 |
| 单点功能（发邮件） | B | 03 |
| 多卖点更新（Cowork） | A（避免与上一张同为 B） | 07 |

## 提示词色彩句（按色族粘贴）

**A 墨黑深底**
```
色族 A 墨黑深底：底 {{INK}}，主字白/{{PAPER}}，仅一处强调色信号蓝 {{SIGNAL}}（占画面≤8%），元数据用 {{MIST}}。
```

**B 纸白浅底**
```
色族 B 纸白浅底：底 {{PAPER}}，主字 {{INK}}，信号蓝 {{SIGNAL}} 作点缀或一格实心块，分割线 {{LINE}}，元数据 {{MIST}}。
```

**C 信号蓝满底**
```
色族 C 信号蓝满底：整幅 {{SIGNAL}} 全出血，文字白/{{PAPER}}，仅用 {{INK}} 小几何块反衬（≤10%）。
```

**D 红黑叙事**
```
色族 D 红黑叙事：上黑 {{INK}} 下红渐变（红仅用于渐变与溶字），主字白，必须保留一处信号蓝 {{SIGNAL}} 小点缀。
```

**E 上浅下深**
```
色族 E 上浅下深：上区 {{PAPER}} 声明，下区 {{INK}}/{{MIST}} 纹理，交界一条信号蓝 {{SIGNAL}} 细线。
```
